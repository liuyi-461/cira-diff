### 结论

1. **LT=18 对比**：SimVP 0.3860±0.0581 vs UNet 0.4884±0.0789；**SimVP 更低（更好），相对优势 21.0%**。
2. **稳健性判定**：均值差 0.1024｜两侧标准差之和 0.1370｜均值差标准误 0.0566（t≈1.81）→ **n=3 下差异未超过方差之和，统计上不显著**——只能报"更优趋势"，不能作因果性断言
3. 逐时效胜负见上表"谁更好"列；CV% 列反映各时效结论的可信度（时效越长 CV 越大，结论越弱）。

> 局限：n=3 且只有聚合指标（无逐样本数组），无法做配对检验（同一样本上 SimVP vs UNet 的成对比较），后者通常比独立两样本检验更有力。

> 引用限制：样本为各 seed 各 1 次训练；rollout 用 128 条子集（与 ly 协议一致）。seed 数越多均值估计越稳（标准误 ≈ CV/√n）。
